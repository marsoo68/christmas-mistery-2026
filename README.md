# Christmas Mystery 2026 — версия 2

Файловете `index.html`, `style.css`, `script.js`, `auth.js`, `christmas-workshop.png` се качват **заедно в корена** на GitHub хранилището. Изображението е в корена, както при работещата версия на сайта.

## Ново
- Supabase регистрация с име, имейл и парола и потвърждение по имейл.
- Вход, изход, възстановяване на сесията и статус на одобрението.
- Правилата са актуализирани за лов на 15 декември, 09:00–23:59.

## Задължителна настройка в Supabase
Authentication → URL Configuration → Site URL: https://marsoo68.github.io/christmas-mistery-2026/
Добави същия URL и в Redirect URLs, ако е необходимо.

## Важно
- В момента регистрацията е отворена **за тестове**; датите 20–30 ноември са информационни. За реалното отваряне/затваряне ще добавим сървърно ограничение.
- Администраторският панел и одобряването още НЕ са реализирани. Не задавай `is_admin=true` чрез публичния клиент.
- Одобрението се чете през RLS политиката от предходната SQL стъпка.
- Потребителите не могат да четат чужди профили.
- Тестът изисква интернет, за да се зареди библиотеката от esm.sh.
- Ако регистрацията дава Database error saving new user, проверете тригера `handle_new_participant` в Supabase.
