# Christmas Mystery 2026 — v4 (пробно теглене)

## Какво е новото
- Елфът Марсел със списъка „повече девойки, повече пари, нова кола“ в „Как се играе?“.
- Разкриване на тайния получател през потребителския профил.
- Одобрените участници виждат само своето назначение.

## Настройка
1. В Supabase SQL Editor изпълни целия файл `v4-test-setup.sql`. Той създава ВРЕМЕННА функция, която връща единствено името на получателя на текущия влязъл потребител.
2. Увери се, че тестовите назначения съществуват (след `SELECT public.test_secret_draw();`).
3. Качи в корена на GitHub хранилището: `index.html`, `style.css`, `script.js`, `auth.js`, `christmas-workshop.png`, `elf-wishlist.png`. Файлът SQL НЕ е нужно да се качва публично.
4. Отвори сайта в два отделни браузърни профила (или нормален и инкогнито прозорец), влез с двата одобрени акаунта и натисни „Разкрий моя получател“.
5. След теста задължително изтрий временната функция с `DROP FUNCTION IF EXISTS public.get_my_test_receiver();`. Преди реалния старт трябва да се направи нова сървърно защитена функция с дата за разкриване.

**Важно:** Във v4 разкриването е нарочно достъпно преди 1 декември за пробата. Не използвай тази версия за реалната игра без премахване на тестовата функция и замяна със сървърна проверка на датата.
