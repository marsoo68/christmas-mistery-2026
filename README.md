# Christmas Mystery 2026 🎄

Първа **визуална** версия на сайта. Включва: коледна сцена, обратно броене, анимиран сняг, прозорец „Как се играе?“ и визуални бутони за регистрация/вход.

⚠️ **Регистрацията, входът, тайното теглене и загадките още НЕ са свързани с Supabase.** Бутоните за вход и регистрация показват информационен прозорец. Не събирайте реални данни, докато не бъде внедрено удостоверяване.

## Пускане на MacBook

1. Разархивирай ZIP файла с двоен клик във Finder.
2. Отвори папката `christmas-mystery-site`.
3. Отвори `index.html` с двоен клик (Safari или Chrome).

## Качване в GitHub

1. Отвори хранилището `marsoo68/christmas-mistery-2026`.
2. Избери **Add file → Upload files**.
3. Качи `index.html`, `style.css`, `script.js` и папката `assets` с изображението (при нужда качи изображението отделно, като запазиш пътя `assets/christmas-workshop.png`).
4. Избери **Commit changes**.
